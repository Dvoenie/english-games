# Фоны для Avatar Quest

Генерировать в ChatGPT. Сохранить в папку `img/` под указанным именем (формат .webp или .png, но тогда поменять расширение в js/data.js). Размер 1920×1080 (16:9).
Если картинки нет, игра показывает цветной градиент, поэтому ничего не ломается.

Общие правила для всех промптов: только пейзажи, без людей и персонажей, без текста, без логотипов и узнаваемых кадров из мультсериала.

Базовый стиль (добавить к каждому): wide 16:9 cinematic landscape illustration, painterly concept-art style, soft light, no people, no characters, no text, no logos, slightly dark so white text stays readable.
