# Ресурсы и лицензии

| Ресурс | Источник | Статус |
|---|---|---|
| Вся графика: карта, город, пальмы, солнце, машины, портреты, иконки, баннеры | Нарисована кодом (SVG) в `js/art.js` специально для игры | Оригинальная работа |
| Звуки и музыкальная петля в стиле synthwave | Синтезируются в браузере через Web Audio API (`js/audio.js`) | Оригинальная работа, аудиофайлов нет |
| Озвучка текстов аудирования | Встроенный синтез речи браузера (Web Speech API) | Голос устройства пользователя |
| Шрифты Russo One, Rubik, JetBrains Mono | Google Fonts | SIL Open Font License 1.1 |
| Тексты и задания с пометкой «ФИПИ» | Открытый банк заданий ЕГЭ ФИПИ 2026 (fipi.ru) | Используются в учебных целях с указанием источника |
| Остальные задания, диалоги, персонажи, сюжет | Написаны для игры | Оригинальная работа |

## Чего в игре нет

* Нет изображений, логотипов, названий, персонажей, музыки и шрифтов из игр
  Grand Theft Auto или других продуктов Rockstar Games / Take-Two Interactive.
* Четыре присланных референс-изображения (официальные арты GTA VI) в игру
  **не включены**: они принадлежат правообладателю. По ним определён только
  общий стиль — неон, закат, пальмы, розово-фиолетовая палитра.
* Нет внешних скриптов, трекеров, аналитики и рекламы.

## Если добавите свои картинки

Фоны и фото-портреты персонажей, сгенерированные по `IMAGE_PROMPTS.md`, принадлежат тому, кто их создал,
в рамках условий сервиса генерации. Перед публикацией проверьте, что на них
нет чужих логотипов и узнаваемых персонажей.
