# English City: Road to 100 Points

Браузерная игра-тренажёр для подготовки к ЕГЭ по английскому языку.
**Английский с Ириной Александровной.**

Неоновый тропический мегаполис, шесть районов, 30 миссий и 185 заданий,
собранных по открытому банку ФИПИ 2026 (с проверкой по ключам) и дополненных
авторскими заданиями того же формата.

> Игровой счёт — это тренировка, а не официальный балл ЕГЭ.

## Как запустить

* **Локально:** откройте `index.html` двойным щелчком. Игра работает прямо из
  папки (file://), сервер не нужен.
* **GitHub Pages:** положите папку `english-city/` в репозиторий (например,
  `english-games/english-city/`), включите Pages. Ссылка будет вида
  `https://<логин>.github.io/english-games/english-city/`. Все пути относительные.

Нужен только браузер (Chrome, Edge, Safari, Firefox; телефон или компьютер).
Интернет нужен лишь для шрифтов Google Fonts. Без него игра работает на
системных шрифтах.

## Что внутри игры

| Район | Что тренирует | Механики |
|---|---|---|
| Coral Beach | Времена, пассив, формы слов (19–29) | Мессенджер, гонка, терминал, радио-перехват, босс |
| Downtown | Словообразование (30–36) | Бизнес-контракты, чат офиса, взлом сейфа, спринт, босс |
| Neon District | Чтение (10–18), сложная грамматика | Расследования, погоня с уровнем розыска ★★★★★, босс |
| International Airport | Аудирование (1–9), письмо (37) | Табло, справочная, бортовое радио, переписка, босс |
| Luxury Hills | Use of English, эссе (38), устная часть | Контракты, Гран-при, опрос, голосовое, радиостудия, босс |
| English City Tower | Финал: все темы | Финальная битва с соперником |

Плюс Retry Contract (повтор ошибок), тренировка по любой теме из справочника
и две секретные миссии за жетоны Echo, спрятанные на карте.

**Прогресс:** деньги, XP, уровни и ранги (Rookie → English City Legend),
репутация, серии ответов, 17 достижений, машины в гараже, обои и титулы.
Районы открываются после победы над боссом предыдущего района.

**Адаптивность:** игра чаще даёт темы, где ученик ошибается, подбирает
сложность по уровню владения темой, а после ошибки добавляет похожее задание.

**Смартфон (кнопка справа внизу):** Сообщения, Карта, Миссии, Профиль,
Достижения, Гараж, English Guide (правила по всем 24 темам), Статистика.

## Статистика для преподавателя

Смартфон → «Статистика». Там точность по каждой теме, оценка освоения,
слабые темы и последние ошибки. Кнопки:

* **Скопировать** — текстовый отчёт в буфер обмена (вставить в сообщения ВК);
* **TXT** и **JSON** — скачать файл.

Данные никуда не отправляются: всё хранится только в браузере ученика
(localStorage, ключ `englishCity.save.v1`). Регистрации нет.

## Как добавить или изменить задания

Весь учебный контент лежит отдельно от логики, в папке `data/`:

* `data/questions.js` — банк заданий. Форматы:

```js
// форма слова
{ id: 'my1', topic: 'gr_passive', type: 'form', lvl: 2,
  text: 'The bridge ___ in 1990.', base: 'BUILD', ans: ['was built'],
  why: 'Пассив в Past Simple: was/were + V3.', ex: 'The house was painted last year.' },
// выбор
{ id: 'my2', topic: 'wf_nouns', type: 'choice', lvl: 1,
  text: 'Her ___ surprised everyone.', opts: ['decide', 'decision', 'decisive'], a: 1, why: '...' },
// собрать предложение (слова в правильном порядке)
{ id: 'my3', topic: 'gr_tenses', type: 'order', lvl: 2,
  text: 'Собери вопрос', words: ['Have', 'you', 'ever', 'been', 'there?'], why: '...' },
// найти ошибку (bad — номер слова с нуля)
{ id: 'my4', topic: 'gr_plural', type: 'fix', lvl: 2,
  s: 'Two childs were playing.', bad: 1, fix: 'children', why: '...' }
```

  `id` должен быть уникальным, `topic` — один из ключей в `data/topics.js`,
  `lvl` — сложность 1–3. В `ans` можно перечислить несколько верных вариантов.
* `data/topics.js` — темы, правила, примеры и типичные ловушки (English Guide).
* `data/texts.js` — тексты для чтения, аудирования, письма и устной части.
* `data/characters.js` — персонажи и их внешность.
* `data/missions.js` — районы, миссии, машины, достижения, ранги.

После правки просто обновите страницу.

## Картинки

Вся графика рисуется кодом (SVG), поэтому игра готова без единой картинки.
Если захотите добавить фоны районов, сгенерируйте их по
[IMAGE_PROMPTS.md](IMAGE_PROMPTS.md), положите в `assets/backgrounds/` и
поставьте `useImageAssets: true` в начале `data/missions.js`.
Фото-портреты персонажей кладутся в `assets/characters/` и включаются флагом
`usePortraitPhotos: true`. Промпты для всех 16 портретов тоже есть в IMAGE_PROMPTS.md.

## Структура

```
index.html
css/        main, phone, minigames, animations, responsive
data/       учебный контент (можно редактировать)
js/         движок: storage, art, audio, progression, ui, dialogue,
            map, missions, statistics, phone, main
js/minigames/  messenger, race, chase, terminal, business,
               investigation, airport, boss, aloud (грузятся по требованию)
assets/     место для необязательных фонов
```

## Доступность

Всё управляется касанием и клавиатурой (Enter, цифры 1–4 для вариантов),
перетаскивания нет. Есть режим «Меньше анимаций» (и учитывается системная
настройка prefers-reduced-motion), выключение звука и музыки, перевод реплик.

## Правовая информация

Оригинальная фанатская образовательная игра, вдохновлённая эстетикой
неоновых тропических мегаполисов. Не связана с Rockstar Games и Take-Two
и не использует их названия, логотипы, персонажей, музыку или изображения.
Подробнее — [ASSET_LICENSES.md](ASSET_LICENSES.md).
