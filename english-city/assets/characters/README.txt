Фото-портреты персонажей (512×512, .webp), сгенерированные по IMAGE_PROMPTS.md.
Уже подключены: sol, dex, ada, victor, echo, priya.
Чтобы добавить ещё: положите файл <id>.webp (для героя игрока — player-<id>.webp)
и впишите id в список photoPortraits в конце data/characters.js.
Персонажи без фото показываются нарисованными.
